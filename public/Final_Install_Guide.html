Agent Culinaire OS

🟦 Windows Installation
FRANÇAIS
Voici les étapes pour installer votre assistant culinaire intelligent Agent Culinaire OS sur Windows.
1

INSTALLATION DU LOGICIEL

  • Lancez le fichier Agent Culinaire OS-Setup.exe.
  • Suivez les instructions à l'écran.
2

INSTALLATION DU CERVEAU IA (OLLAMA)

  • Ollama est une plateforme sécurisée qui fait tourner des modèles d'IA localement pour une confidentialité totale.
  • Téléchargez et installez Ollama : https://ollama.com/download/windows
  • Une fois installé, ouvrez l'invite de commande (cmd) ou PowerShell et tapez : ollama pull llama3.2
  • Dans Agent Culinaire OS, allez dans "PARAMÈTRES" -> "IA" et cliquez sur "Tester Connexion".
3

ACTIVATION DE LA LICENCE

  • Allez dans l'onglet "PARAMÈTRES". Notez le "Machine ID" et envoyez-le à votre administrateur pour recevoir votre clé.
  • Entrez la clé et cliquez sur "Activer".
4

ACCÈS SMARTPHONE (WIFI)

  • Dans les paramètres de Agent Culinaire OS, scannez le QR Code apparaissant à l'écran.
5

SAUVEGARDE

  • Prenez note de l'emplacement de vos données (généralement dans %APPDATA%\Agent Culinaire OS). Copiez agent_culinaire.db et le dossier uploads régulièrement.

🟦 Windows Installation
ENGLISH
Here are the steps to install your intelligent culinary assistant Agent Culinaire OS on Windows.
1

SOFTWARE INSTALLATION

  • Run Agent Culinaire OS-Setup.exe.
  • Follow the on-screen instructions.
2

AI BRAIN INSTALLATION (OLLAMA)

  • Ollama is a secure platform that runs AI models locally for absolute privacy.
  • Download and install Ollama: https://ollama.com/download/windows
  • Once installed, open Command Prompt (cmd) or PowerShell and type: ollama pull llama3.2
  • Inside Agent Culinaire OS, go to "SETTINGS" -> "AI" and click on "Test Connection".
3

LICENSE ACTIVATION

  • Go to the "SETTINGS" tab. Note the "Machine ID" and send it to your administrator to receive your key.
  • Input the key and click "Activate".
4

SMARTPHONE ACCESS (WIFI)

  • In Agent Culinaire OS settings, scan the on-screen QR Code.
5

BACKUP

  • Take note of your data location (usually %APPDATA%\Agent Culinaire OS). Copy agent_culinaire.db and the uploads folder regularly.

DEUTSCH
Hier sind die Schritte zur Installation Ihres intelligenten Küchenassistenten Agent Culinaire OS unter Windows.
1

SOFTWARE-INSTALLATION

  • Führen Sie die Datei Agent Culinaire OS-Setup.exe aus.
  • Folgen Sie den Anweisungen auf dem Bildschirm.

BACKUP

🐧 Linux Installation
FRANÇAIS
Voici les étapes pour installer Agent Culinaire OS sur Linux (Ubuntu/Debian).
1

EXÉCUTION DU LOGICIEL

  • Vous avez un fichier .AppImage.
  • Clic droit sur le fichier -> Propriétés > Onglet Permissions.
  • Cochez "Autoriser l'exécution du fichier comme un programme".
  • Fermez et double-cliquez pour lancer Agent Culinaire OS.
  • Terminal: chmod +x Agent Culinaire OS-1.0.0.AppImage puis ./Agent Culinaire OS-1.0.0.AppImage
2

CERVEAU IA (OLLAMA)

  • Ouvrez un terminal: curl -fsSL https://ollama.com/install.sh | sh
  • Une fois installé, tapez dans ce même terminal : ollama pull llama3.2
  • Dans Agent Culinaire OS -> "PARAMÈTRES" -> "IA" -> "Tester Connexion".
3

ACTIVATION DE LA LICENCE

  • Dans "PARAMÈTRES", notez le "Machine ID" et envoyez-le au support.
  • Renseignez la clé et activez l'application.
4

SAUVEGARDE ET ACCÈS SMARTPHONE

  • QR Code Wi-Fi disponible dans les paramètres.
  • Copiez TOUJOURS agent_culinaire.db et le dossier uploads avant une maj. (Dans le répertoire de l'AppImage ou ~/.config/agent-culinaire-os).

🐧 Linux Installation
ENGLISH
Here are the steps to install Agent Culinaire OS on Linux (Ubuntu/Debian based).
1

RUNNING THE SOFTWARE

  • You have an .AppImage file.
  • Right-click on the file -> Properties > Permissions tab.
  • Check "Allow executing file as program".
  • Close and double-click to launch Agent Culinaire OS.
  • Terminal: chmod +x Agent Culinaire OS-1.0.0.AppImage then ./Agent Culinaire OS-1.0.0.AppImage
2

AI BRAIN (OLLAMA)

  • Open a terminal: curl -fsSL https://ollama.com/install.sh | sh
  • Once installed, type in the terminal: ollama pull llama3.2
  • Inside Agent Culinaire OS -> "SETTINGS" -> "AI" -> "Test Connection".
3

LICENSE ACTIVATION

  • Go to "SETTINGS", note the "Machine ID" and send it to support.
  • Enter the received key and activate.
4

BACKUP AND SMARTPHONE ACCESS

  • Wi-Fi QR Code available in settings.
  • ALWAYS backup agent_culinaire.db and the uploads folder before updates. (In the AppImage directory or ~/.config/agent-culinaire-os).
