# GH-600 — couverture des 6 domaines par claus.io

> **Ce n'est PAS une certification.** « GitHub Certified: Agentic AI Developer »
> (exam GH-600) est une certification **individuelle**, proctorée, obtenue en
> passant l'examen. Un dépôt ne peut pas être certifié. Ce document montre
> quelles parties de claus.io constituent une **preuve de terrain rejouable**
> pour chaque domaine du programme officiel :
> https://learn.microsoft.com/en-us/credentials/certifications/agentic-ai-developer/

Toutes les commandes ci-dessous tournent en local, sans LLM réel, sans réseau
et sans clé (le cerveau injecté est le cerveau factice déterministe).

## La règle qui commande tout

Aucun outil MCP et aucun rôle d'orchestration n'écrit dans une table métier
(`inventory`, `recipes`, `haccp`…). La seule écriture possible est la boîte
`suggestions`, dont l'application est rejouée par la route cible **sous la
signature du maître**. Ce n'est pas une convention documentaire : c'est vérifié
par `verify:agents` (comparaison du nombre de lignes `inventory` avant/après un
appel d'outil) et par la gate de session (`ECRITURES_AGENT`, *match exact*).

## Rejouer les preuves

```bash
npm run lint                 # tsc --noEmit
npm test                     # unités, dont test/unit/evals-agents.test.ts
npm run verify:agents        # outils + orchestration + evals + MCP stdio
npm run verify:agents-http   # vrai serveur : routes montées + session + artifacts
npm run verify:agents-mord   # mordant : les fautes injectées DOIVENT rougir
npm run verify:donnees-anciennes   # compatibilité des bases antérieures (e2e)
```

`verify:agents` écrit ses sorties dans `test/tmp-agents/<pid>` (ignoré par git) :
aucune donnée réelle n'est touchée.

## Configurer un client MCP

Le serveur stdio parle au même registre que la route HTTP :

```json
{
  "mcpServers": {
    "clausio-local": {
      "command": "npx",
      "args": ["tsx", "mcp-server.ts"],
      "env": { "COOKDRIVE_AGENT_OFF": "0" }
    }
  }
}
```

- Outils disponibles : `etat_inventaire`, `alertes_actives`, `dlc_proches`,
  `temperature_derniere` (lecture) et `proposer_action` (boîte de suggestions).
- `COOKDRIVE_MCP_OUTILS="etat_inventaire,dlc_proches"` réduit l'allow-list aux
  noms donnés (match exact). `COOKDRIVE_AGENT_OFF=1` retire `proposer_action`.
- `mcp-server.ts` n'a **pas** d'authentification : il est lancé localement par
  le maître, jamais exposé sur un réseau. La voie HTTP (`/api/mcp/*`) passe,
  elle, par la session et le journal d'audit.

## Pour aller plus loin (ce que ce dépôt ne prétend pas)

- La certification s'obtient en s'inscrivant à l'examen (Pearson VUE, 120 min,
  anglais, score 700/1000) : le [guide d'étude GH-600](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/gh-600)
  liste les formations officielles, notamment sur les serveurs MCP distants
  GitHub, les registres MCP et l'exécution d'agents en CI — sujets que claus.io
  illustre localement mais ne couvre pas tous (pas de Copilot Cloud Agent ici).
- Ce document est une cartographie honnête, pas un badge ni une auto-certification.
